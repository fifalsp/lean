# Lean formalizations

This repository collects machine-checked formalizations of research mathematics.
Each project is kept in a dated, self-contained subfolder so that it can pin its
own Lean and mathlib versions.

## Projects

| Started | Project | Status |
| --- | --- | --- |
| 2026-08 | [Rigorous Low-Degree Implications for Planted Subgraph Detection: Noise and Treewidth](2608-low-degree-indistinguishability/) | All numbered results proved, including Theorems 1.1, 1.2, and A.3; no `sorry` or axioms |

## Repository convention

Project folders use the prefix `YYMM-`. For example,
`2608-low-degree-indistinguishability` records that the formalization began in
August 2026.

To build a project, enter its folder and follow the instructions in its README.
